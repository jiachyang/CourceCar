# 车辆配置与接线（当前真值）

> 本文件是车辆**硬件接线、轮位与车头朝向**的唯一真值入口。
> 修改接线时先改本文件，再同步各模块 `*_config.hpp` 与需求表
> `docs/chassis_requirements.md`。控制接口仍以车体坐标为准。

- 当前版本：rev.6（车道保持接入；安装几何待标定）
- 主控：VEX V5 Brain（PROS，Smart Port 1～21）

## 1. 车头方向与坐标系

控制使用的右手车体坐标系（与代码一致）：

- 原点：底盘几何中心。
- **+X：车头方向**（前进 / `vx > 0`）。
- **+Y：车体左侧**（左移 / `vy > 0`）。
- **+Z：竖直向上**；`omega > 0` 为俯视逆时针。

车头不是沿某一条框架边，而是沿正方形的前后对角线。若用**框架边长坐标**描述
（x 轴沿框架一条边、y 轴沿相邻边，原点在中心）：

> **车头方向 = 从 +x 正方向向 +y 正方向偏转 45°**，
> 即单位向量 `(1/√2, 1/√2)`。

说明：

- 这个 45° 是对**安装/场地朝向**的描述，不改变控制坐标系的定义；
- `core::MotionCommand` 和逆运动学仍以车体 +X = 车头、+Y = 左侧计算，
  **不需要把 45° 写进 IK 公式**；
- 车体 +X 轴与框架边长坐标的 +x/+y 轴相差 45°。

### 1.1 IMU 安装朝向

IMU 绕竖直轴旋转安装，因此“IMU 的 +x 轴”不再等于车头：

- 旧约定：IMU +x = 车头；
- 当前约定：**车头 = IMU +x 向 +y 偏 45°**；
- 代码用 `imu::kMountingYawOffsetRad = +π/4` 把这个固定夹角加到
  `heading / rotation` 上；
- `gyro.z`（偏航角速度）不受这个常值偏置影响，`yawSign` 也保持不变；
- 航向保持是“目标 − 当前”的相对闭环，常值偏置会在其中抵消，
  **不会改变航向保持的物理行为**，只改变绝对航向/遥测的零点。

符号约定与修正：

- 若实际车头在 IMU +x 的**顺时针**侧，把 `kMountingYawOffsetRad` 改为 **−π/4**；
- 若启动时改为用**车头**（而不是 IMU +x）对准场地参考，把偏置设为 **0**；
- 上电后让 IMU +x 对准场地参考，静止时 `rot` 应显示 **+45°**；
  再把车头转到该参考方向，`rot` 应显示 **0°**。

> 注意：这里的 45° 是“IMU +x → 车头”的夹角，和 §1 中
> “框架边长 +x → 车头”的 45° 是两个不同参照系；它们恰好都是 45°，不要混用。

## 3. 四轮编号与安装位置

四轮索引在全工程统一为 **FL, FR, RL, RR**。车体坐标下的轮心位置：

| 轮 | 名称 | 电机端口 | 车体坐标 `(x, y)` | 几何说明 |
| --- | --- | --- | --- | --- |
| FL | 左前轮 | **1** | `(+a, +a)` | 左前方轮 |
| FR | 右前轮 | **3** | `(+a, −a)` | 右前方轮 |
| RL | 左后轮 | **2** | `(−a, +a)` | 左后方轮 |
| RR | 右后轮 | **4** | `(−a, −a)` | 右后方轮 |

其中：

- `R = 0.1475 m`：底盘中心到轮心距离；
- `a = R/√2 ≈ 0.1043 m`：轮心在车体 x / y 方向的分量；
- `r_wheel = 0.05 m`：车轮有效半径；
- 直驱，传动比 `1:1`。

> 电机端口与轮号的对应关系是：**1=FL、2=RL、3=FR、4=RR**。
> `ChassisConfig::motorPorts` 的数组顺序是 **FL, FR, RL, RR**，因此实际填入
> `{1, 3, 2, 4}`，不是 `{1, 2, 3, 4}`。

## 5. 车头 45° 与轮位的关系

若把框架边长坐标的 `+x` 取为向右、`+y` 取为向上（右手系，`+z` 向上），
则车头方向为右上方 45°。此时四个轮心（位于正方形四条边的中点）为：

| 轮 | 框架边长坐标 `(x, y)` |
| --- | --- |
| FL | `(0, +R)` |
| FR | `(+R, 0)` |
| RL | `(−R, 0)` |
| RR | `(0, −R)` |

这只是同一套机械布局在另一个坐标系中的表示；控制代码不需要做坐标变换，
因为上层输入和 IK 都使用车体 +X/+Y。

> 注意：FL/FR/RL/RR 是**相对车头方向**命名的，不是按框架边长坐标的
> “上下左右”命名；因此车头对角线上，FL 会落在框架的一条侧边中点。
