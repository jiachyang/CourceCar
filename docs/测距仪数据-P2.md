## 1. 规格（先立标尺，再谈实测）

| 项 | 值 | 来源 |
| --- | --- | --- |
| 量程 | **20 – 2000 mm** | vexide 硬件说明（见文末参考） |
| 精度 | **<200 mm 时 ±15 mm；>200 mm 时 ±5%** | 同上 |
| 原理 | Class 1 激光，单点窄光束（类似手机 proximity） | 同上 |
| 更新率 | VEXos 每 **10 ms** 处理一次传感器更新 | 同上 |
| 无目标返回值 | **9999** | PROS `distance.hpp` |
| 读取失败 | **2147483647**（`PROS_ERR`） | PROS `error.h` |
| 置信度范围 | 0 – 63 | vexide / PROS |
| 物体大小 `size` | 0–400（单位无量纲），**无有效物体时为 −1** | vexide（说明其为 VEXCode `sizeType` 遗留，意义存疑） |
| 本工程采用的窗口 | 有效判据 = `20 ≤ d ≤ 2000`；另设 `kRangeMinM=0.02 m` | `mazecar/include/mazecar/config.hpp:179` 任务书规格 |

> 任务书里还有一条已被本次实测验证的记录：「目标小于 200 mm 时 confidence 可能固定为 10」——
> 本次在 19 mm / 20 mm / 23.6 mm 三处读数上，`conf` **全部等于 10**。

## 2. 测试方法

两个模式、两个槽位，全部从 shell 命令行触发（`pros v5 run <slot>`），数据从 User 口读：

| 模式 | 槽位 | 行为 | 采样率 |
| --- | --- | --- | --- |
| A 实时回传 | 4 | 打印每条原始读数（距离/置信度/物体大小/速度），每秒一行小结 | 20 Hz（50 ms） |
| B 漂移测定 | 5 | 每 30 s 一个窗口，输出均值/标准差/极差/首末段差/最小二乘斜率，并与规格带对照 | 50 Hz（20 ms） |

```bash
# shell 1：看数据
cat /dev/ttyACM1
# shell 2：触发
pros v5 run 4        # 模式 A
pros v5 run 5        # 模式 B
# 或者一条命令：
bash scripts/mode-stream.sh 10      # 实时回传 10 秒
bash scripts/mode-drift.sh 34       # 漂移测定（一个 30 s 窗口 + 报告）
```

> **为什么不做“程序内按键切模式”**：PROS 4.2.2 的 stdin 是桩函数 ——
> `libpros.a` 的 `vfs.c.o` 里 `_read` 反汇编就是 `mov r0, #0; bx lr`，`getchar()` 永远返回 EOF，
> 程序读不到串口发来的任何字符。所以“命令行触发”只能落在**启动哪个槽位**上。

## 3. 实测数据

### 3.1 采样性能（达标验证）

| 模式 | 实测 | 结论 |
| --- | --- | --- |
| A 实时回传 | 每秒 20–21 个样本（连续 10 s） | 20 Hz 目标达成 |
| B 漂移测定 | 30 s 窗口共 **1500** 个样本（727 有效 + 773 过近） | **恰好 50.0 Hz**，20 ms 周期无漂移 |

### 3.2 场景 1：目标 ≈ 23.6 mm（模式 A，10 s）

首读 `23 mm, conf=10, size=1`。每秒统计：

| 秒 | 样本 | 均值 | 最小 | 最大 | 极差 | 无目标 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 21 | 23.5 | 22 | 26 | 4 | 0 |
| 2 | 20 | 23.9 | 22 | 26 | 4 | 0 |
| 3 | 20 | 23.5 | 23 | 24 | 1 | 0 |
| 4 | 20 | 23.5 | 22 | 26 | 4 | 0 |
| 5 | 20 | 23.7 | 23 | 26 | 3 | 0 |
| 6 | 20 | 23.6 | 22 | 26 | 4 | 0 |
| 7 | 20 | 23.6 | 22 | 26 | 4 | 0 |
| 8 | 20 | 23.6 | 22 | 26 | 4 | 0 |
| 9 | 20 | 23.9 | 23 | 26 | 3 | 0 |

10 秒内均值漂在 **23.5–23.9 mm**（极差 0.4 mm），逐秒极差 1–4 mm，无一次丢目标。

### 3.3 场景 2：目标 ≈ 20 mm（模式 B，30 s 窗口 #1）—— 本次唯一完整漂移窗口

| 指标 | 值 |
| --- | --- |
| 样本 | 有效 **727** / 过近(<20 mm) **773** / 无目标 **0** / 错误 **0** |
| 均值 | **20.11 mm** |
| 标准差 | **0.31 mm** |
| 最小 / 最大 / 极差 | 20 / 21 / **1 mm** |
| 前 5 s 均值 → 后 5 s 均值 | 20.13 → 20.02（**−0.11 mm**） |
| 最小二乘斜率 | −0.0022 mm/s = **−0.13 mm/min**（n=727） |
| 置信度均值 | 10.0 |
| 规格带 | 该距离处 ±15 mm |
| 判定 | 极差 1 mm **远在规格带内** → 属传感器噪声，**不构成漂移** |

### 3.4 场景 3：目标 10–11 mm（模式 A，6 s，有效性修复后）

117 条读数**全部**被判为 `TOO CLOSE <20mm`，有效样本 **0**，逐秒 `invalid` = 20–21。

### 3.5 场景 4：目标 ≈ 1 mm（模式 A，8 s，有效性修复前）

读数恒定 `1 mm`、`conf=10`、`size=-1`；逐秒统计 n=21、mean=1.0、极差 0、`no_target=0`。

> 这个场景是本次最重要的“反面教材”：**低于量程下限时传感器不返回 9999，而是返回 1/10/11/18/19 之类的小值**。
> 若按“不等于 9999 就算有效”判定，会把 11 mm 的垃圾读数统计成「均值 11.0 mm、极差 0、斜率 0」——
> 看起来是完美零漂，实际全是无效数据。

## 4. 性能结论

| 指标 | 实测值 | 说明 |
| --- | --- | --- |
| 分辨率 | **1 mm** | 读数始终为整数 |
| 短时重复性 | sd **0.31 mm** / 极差 **1 mm** @20 mm；极差 3–4 mm @23.6 mm | 这是测漂移时真正起作用的指标 |
| 绝对精度 | 未测（需卷尺/标定板）；规格为 ±15 mm @<200 mm | 规格是“偏置”指标，不影响稳定性测量 |
| 漂移检出下限 | ~**0.3 mm** 量级（受短时重复性限制） | 30 s 窗口可分辨 ~0.1 mm/min 量级的斜率 |
| 采样率 | A 模式 20 Hz；B 模式 50.0 Hz | 20 ms 周期精确 |
| 响应延迟 | **未测** | 需挡板/已知运动才能测 |
| 置信度 | **<200 mm 时恒为 10**（满量程 63 的 16%） | **不能**用作有效性判据 |
| 物体分类 `size` | 有效目标 1；无有效物体 −1 | |
| 速度读数 | 静止时 −0.08 ~ +0.00 m/s | 噪声底 |
| 量程下限行为 | <20 mm 返回 1/10/11/18/19 等小值（**非 9999**） | 必须显式加 `d ≥ 20` 判据 |
| 无目标（9999） | 本次**未出现** | 所有场景目标都在 20 mm 以内或 ~23.6 mm |

## 5. 数据可信度与已知问题

1. **目标几何没有固定**：四轮观测依次为 1 mm → 23.6 mm → 20 mm → 10–11 mm。
   因此第 3 节的四组数据是**不同几何条件下的快照**，不是同一固定点的重复测量；
   3.3 的“斜率 −0.13 mm/min”只能在“窗口内几何未动”的前提下解读。
2. 修复的三个问题（都影响数据本身）：
   - LCD 上写中文导致 LVGL 缺字形警告刷屏（`glyph dsc. not found for U+6781`）污染串口流 → 改 ASCII 后实测警告数 **0**；
   - 有效性判据由 `d > 0` 改为 `20 ≤ d ≤ 2000`，并把“过近”单独计数（见 3.4/3.5）；
   - `mode-drift.sh` 用 `cat | tee` 时只杀得掉 `tee`、`cat` 永远挂住管道 → 改单进程 `cat > log`。
3. 30 s 窗口只跑了 **1 个**（程序支持连续多窗口，`KEEP=1 bash scripts/mode-drift.sh` 可连续观察）。

## 6. 尚未测量（后续可补）

- **>200 mm 区间**的精度与重复性（规格 ±5%，完全没有实测点）；
- 响应时间、遮挡→恢复时间、上电初始化时间；
- 长时间（>30 s 至数分钟）漂移与温漂；
- 不同材质 / 颜色 / 反射率 / 入射角的影响；
- 多目标与边缘场景（量程边界 20 mm、2000 mm 附近的读数行为）；
- 无目标时的 9999 行为与恢复时间；
- 与 EKF 的联合标定：把 `kRangeMinM` / `kRangeMaxM` / `kRangeMinConfidence` 从占位值改成实测值。
