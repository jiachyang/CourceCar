## 1.1 更新硬件端口（IMU 11、Radio 5）

**问题/需求**：实际接线为 **陀螺仪(IMU) 在 Smart Port 11**、**V5 Robot Radio 在 Smart Port 5**。

**定位**：原 `kPort=5` 是 IMU，需要改。

**解决**
- `include/imu/imu_config.hpp`：`kPort = 11`。
- `include/radio/radio_config.hpp`：新增 `kPort = 5`，并在 `RadioConfig` 里加 `port` 字段。

**注意**：本工程用 `pros::Controller`（模式 A），无线链路由 VEXos 接管，
**Radio 的端口号不参与任何 PROS 调用**，只是登记硬件接线真值。

**同步文档**：`docs/chassis_requirements.md`（HW-005→11，新增 HW-010 Radio 端口，
追加 rev.4）、`docs/chassis_design.md`（数据流图）。

## 1.2 遥控前后左右方向全反

**现象**：推杆向前→车后退，推杆左/右→相反应方向。

**定位**：这是**遥控映射符号**问题，不是电机接线；`RadioConfig` 的 `invert*` 就是为此设计的。

**解决**（`include/radio/radio_config.hpp`）
```cpp
bool invertForward = true;   // 实测：推杆向上后退 → 反转
bool invertStrafe  = true;   // 实测：推杆左右相反 → 反转
bool invertTurn    = true;   // 实测：右摇杆转向相反 → 反转
```
只改配置，**不改任何底盘代码**。

> 原理：同时翻转 `vx`、`vy` 等价于 180° 旋转，不影响自转轴；
> 右摇杆另由 `invertTurn` 处理。

## 1.3 左摇杆要"前后左右独立"，不要斜向

**需求**：左摇杆直上/直下就是纯前进/后退（便于走直线测试），不要斜推走斜线。

**解决**（`include/radio/input_mapping.cpp` + `input_mapping.hpp`）
- 新增参数 `snapLeftStickToAxis`；
- 逻辑：只保留绝对值较大的一个轴，另一个置 0（平局取前后轴）；
- 配置 `kSnapLeftStickToAxis = true`（`radio_config.hpp`）。

右摇杆 omega 不受影响。日后想要斜向平移，把这一个开关置 false 即可。

**测试**：`tests/native/test_radio_mapping.cpp` 增加正交优先用例（45° 取前后、
偏右取左右、不影响自转）。
