# 03 航向保持与"主动旋转结束重锁目标"

## 3.1 开启航向 PID

`include/config/robot_config.hpp`：

```cpp
bool enableImu        = true;
bool enableImuHeading = true;
```

航向 PID 实现：`src/chassis/heading_controller.cpp`（纯逻辑，无硬件）。
目标航向 `targetRad_` 在 **上电 5s** 后由 `Chassis::update` 锁存一次
（`chassis.cpp`：`!hasTarget() && now-bootMs_ >= kHeadingLatchDelayMs`）。

方向由 `imu_config.hpp` 的 `yawSign` 决定（实测改为 `+1.0`）。

## 3.2 问题：转弯之后车自己在缓慢旋转

**现象**：右摇杆转完松手后，车不保持松手朝向，而是**慢慢转回开机时的朝向**。

**定位**：`HeadingController` 原逻辑里，**主动旋转期间只是旁路航向保持，
但目标仍是开机锁存的旧值**。所以松手后 PID 会把车拉回旧目标。

**解决**（`src/chassis/heading_controller.cpp`）：主动旋转期间**让目标跟随当前朝向**：

```cpp
const bool active = std::fabs(externalOmega) > 1e-6;
if (active) {
    targetRad_ = core::wrapToPi(yawRad);   // ← 主动旋转期间持续重锁目标
    integ_ = 0.0;
    prevErr_ = 0.0;
    wasActive_ = true;
    return externalOmega;
}
```

于是**松手瞬间目标 = 松手时的朝向**，误差≈0，不再"转回旧目标"。

**测试**：`tests/native/test_heading_controller.cpp` 增加"主动旋转结束重锁目标"用例。

## 3.3 排障过程的教训

- 一开始怀疑"目标冻结在调参窗口里"是错的：**目标值本身不会让轮子转**，
  真正驱动的是 PID 输出（`tw`）。定位时必须看 **PID 输出**，而不是只看目标。
- 因此后续把 **PID 的 err/P/I/D/corr 全部回传**（见 05），才能定量判断。
