# 07 串口实时调参 / 诊断工具

## 7.1 固件侧：`$P` 帧（`src/diag/telemetry.cpp` 的 `printTuneFrame`）

~25–50 Hz 输出一行紧凑 CSV（PROS 会带 `sout` 前缀，Python 在行内找 `$P,`）。
共 **39 个字段**（`ms` + 38 个载荷）：

```
ms,
tvx,tvy,            目标平移 [mm/s]
tw,wraw,            施加 omega / 斜坡前 omega [mrad/s]
rot,gz,             IMU 偏航角[mrad] / 陀螺角速度[mrad/s]
ht,herr,            航向目标 / 误差 [mrad]
hP,hI,hD,hcorr,     PID 的 P/I/D 项 + 总输出 [mrad/s]
hext,hrot,          外部 omega[mrad/s] / 是否主动旋转
aFL,aFR,aRL,aRR,    四轮实测 [milli-rpm ×1000]
cFL,cFR,cRL,cRR,    四轮命令 [milli-rpm ×1000]
bias,drift,         陀螺零偏 / 漂移率 [mdps]
st,bm,imu,hdg,      IMU 原始状态 / 零偏已测 / IMU有效 / 航向使能
rc,                 遥控有效
kp,ki,kd,           PID 增益 ×1000
intLim,             积分状态限幅 [mrad·s]
pLim,iLim,dLim,     P/I/D 单项限幅 [mrad/s]
outLim              总输出限幅 [mrad/s]
ff                  静摩擦前馈生效值 [mrad/s]
```

原啰嗦的 `[t]` 行已删除（`$P` 覆盖其全部字段）。帧格式与字段表只在
`src/diag/telemetry.cpp` 的 `DIAG_TUNE_FIELDS` 定义一次，字段数由 `static_assert` 守住。

## 7.2 上位机：`test/pid_tune.py`（纯标准库）

不需要 `pyserial`/`matplotlib`，用 **termios + tkinter**。

- 一个**主窗口**：固定位置中文诊断表（每个量一格，含 P/I/D 与各自限幅同屏对照）。
- **每条曲线一个独立窗口**（类 Ozone 变量图像）：
  vx / vy / ω / 目标航向 vs 实测偏航。
  每个窗口带**网格、Y/X 轴刻度、图例、目标/当前/差 大字读数**。
- 航向角显示为 **度（°）**，角速度/PID 修正为 **度/秒（°/s）**；
  固件 `$P` 原始帧仍是 mrad，由 Python 解析后换算。
- 曲线窗口操作：**单击放置竖线游标**（显示该时刻目标/读取/差）、
  **滚轮缩放**、**左键拖动平移**、**双击跟随最新并清除游标**；
  Y 轴按可见区间自动缩放；保留 120s 历史。时间轴刻度随缩放自动换挡。
- 选项：`--csv FILE` 存全字段 CSV（含 `mvx,mvy`，旋转量已换算为度）；
  `--headless N` 无界面采集。
- **角度环 vs 速度环**：当前航向保持是**角度 PID**，输入是航向角误差，
  输出是 ω 指令；没有独立的角速度闭环。“自转 ω”窗口只是把 ω 指令和
  陀螺实测放在一起对照。主窗口顶部大字号显示的是“角度目标/角度实测/角度误差”。

## 7.3 为什么做成这样（踩过的坑）

1. **先有数据再判断**：最初界面只有拥挤的一行字符串，看不清；改成固定格子 + 中文标签。
2. **曲线不能挤在一个窗口**：改成每条曲线独立窗口，便于放大看细节。
3. **PROS 会加 `sout` 前缀**：解析必须在行内 `find("$P,")`，不能 `startswith`。
4. **轮速要 milli-rpm**：否则 0.37 rpm 显示成 0，误判为"没输出"（见 06）。

## 7.5 `$D` 帧的车道保持字段（v2.1）

`$D` 仍以 20 Hz 输出四路测距，末尾追加 **30** 个车道保持字段 + **3** 个安全层字段（旧解析器会忽略）：

```
$D,ms,instMask,validMask,
   dF,cF,sF,vF,tF,  dR,cR,sR,vR,tR,  dL,cL,sL,vL,tL,  dRt,cRt,sRt,vRt,tRt,
   laneMode,laneGroup,nearMask,validMask,
   leftMm,rightMm,centerErrMm,pMms,iMms,dMms,corrMms,outVxMms,outVyMms,outOmegaMradS,
   filterS0..S3,freshMask,leftClass,corridorWidthMm,laneReason,
   qualityMilli,rightClass,pairScoreMilli,laneFlags,
   sideLeftRawMm,sideRightRawMm,pidTargetMmS,tooCloseMask,
   safetyScaleMilli,safetyNearestMm,safetyFlags
```

- `laneMode`：0=关 1=NO_PAIR 2=INSUFFICIENT_DATA 3=NO_CORRIDOR
  4=TRACKING 5=DEGRADED 6=TOO_CLOSE；
- `laneGroup`：-1=未选，0=Group A(前后)，1=Group B(左右)；
- `nearMask/validMask/freshMask`：bit0..3 = 逻辑 S0..S3；
  `nearMask` 只表示 `NEAR_RETURN`，`validMask` 表示最近有效回波仍在 180 ms 内，
  `freshMask` 表示在 42 ms 新鲜窗口内；
- `leftMm/rightMm`：当前通道对运动左/右传感器的**滤波距离**；
- `centerErrMm`：`(右墙距-左墙距)/2`，**向右为正**；
- `pMms/iMms/dMms/corrMms`：横向 PD 各项与最终纠偏 [mm/s]；默认 Ki=0；
- `filterS0..S3`：四路滤波距离，顺序为逻辑 S0..S3 = **前/左/后/右**
  （注意与前 20 个原始字段的“前/后/左/右”顺序不同）；
- `leftClass/rightClass`：0=UNKNOWN 1=NEAR_RETURN 2=MID_RETURN 3=FAR_RETURN；
  `FAR_RETURN` 是有效远距回波，**不是无墙/无目标**；
- `corridorWidthMm`：两侧滤波距离 + 传感器几何宽度；`laneReason`：模式原因码
  （0 none / 1 disabled / 2 config / 3 input / 4 no-pair /
  5 insufficient-data / 6 no-corridor / 7 tracking / 8 too-close /
  9 stale-measurement / 10 lost-wall-hold）；
- `qualityMilli`：1.0=TRACKING，0.5=DEGRADED/TOO_CLOSE；
- `pairScoreMilli`：`max(|通道法向·传感器轴|)`；低于 `0.82` 不选对；
- `laneFlags`：bit0 active、bit1 degraded、bit2 tooClose、bit3 pairValid、
  bit4 modeChanged、bit5 groupChanged、bit6 headingValid、bit7 corridorWidthValid、
  bit8 corridor、bit9 decay、bit10 fallbackPair；
- `sideLeftRawMm/sideRightRawMm`：物理左/右（逻辑 S1/S3）原始距离；
- `pidTargetMmS`：限幅后、平滑前的横向目标；TOO_CLOSE 时为过近排斥量；
- `tooCloseMask`：bit0=左过近，bit1=右过近；
- `outVxMms/outVyMms/outOmegaMradS`：LaneKeeper 输出命令；其中 omega 是透传
  的基础值，**最终**航向修正后的 omega 看 `$P` 的 `tw`；
- 末尾 3 个安全层字段：`safetyScaleMilli`（平移限速比例 ×1000）、
  `safetyNearestMm`（运动方向最近障碍）、`safetyFlags`
  （bit0 enabled、bit1 configValid、bit2 limited、bit3 stopped、bit4 headingBlocked）。

过近时横向 PD 被旁路，横向输出是独立的过近排斥量。LaneKeeper **不改变巡航速度**；
前向 ToF 限速由独立 `SafetySupervisor` 在合成命令之后执行。
`test/lane_plot.py` 会同时画两侧原始距离、误差和横向控制输出，并写 CSV。

IMU 航向/目标/误差在 `$P` 的 `rot/ht/herr`，与 `$D` 同一 20 ms 时基。

字段顺序只在 `src/diag/telemetry.cpp` 的 `printDistanceFrame()` 定义；
修改时必须同步 `test/distance_monitor.py` 的 `LANE_FIELDS` 与 `test/README.md`。
