# 04 静置漂移补偿（引入 → 反噬 → 关闭）

## 4.1 需求

希望静止时航向不漂。

## 4.2 第一版：用陀螺零偏去扣角度（错的）

做法：开机后静置 2s 测陀螺 Z 零偏 `gyroBiasDps`，然后
`rotationRad -= gyroBiasDps·deg2rad·yawSign·Δt`。

**结果不对**：实测 43s 静置里 `rot` 反而以约 +5 mdps 漂，
而补偿量恰好也是这么多 → 说明 **VEXos 的 `get_rotation()` 本身已做过零偏积分补偿**，
再扣一次是"二次补偿"，**凭空制造漂移**。

## 4.3 第二版：改测"角度漂移率"（仍然危险）

改成实测 `get_rotation()` 的漂移率 `gyroDriftDps` 再补偿，并加噪声门限。

**结果会引发无输入自转**：如果那 2s 测量窗口里**车在动**，
测出的"漂移率"其实是车在转。把这个值扣到 `rot` 上后：

- `rot` 被补成一个**假的恒定值**（看起来不动）；
- 航向环为了"追"这个假漂移，**持续下旋转命令**（`tw≈−70 mrad/s`）；
- 而被扣掉的量正好抵消真实转动 → 遥测里 `rot` 看似不动、车却在真转。

这解释了"无输入但缓慢自转"。

## 4.4 最终：关闭角度补偿

`src/modules/imu.cpp` 加开关，**默认关闭**：

```cpp
constexpr bool kApplyRotationDriftComp = false;   // 不把测得的漂移率扣到角度上
```

理由：实测 `get_rotation()` 静置 43s / 70s `rot` 恒 0，**本来就不需要补偿**；
陀螺零偏 `gyroBiasDps` 仍测量并回传（仅用于诊断/角速度上报，不参与控制）。

## 4.5 教训

- 测量类补偿**一定要验证**"被补偿的量本身是否已经补偿过"。
- 短窗口测漂移会被运动污染，且量级与噪声同阶；**宁可不动，也不要引入假漂移**。
- 遥测要带 `bias/drift`，否则无法判断测量是否可信（曾出现 `bias≈40000 mdps`，
  说明开机 2s 内车在快速转）。
