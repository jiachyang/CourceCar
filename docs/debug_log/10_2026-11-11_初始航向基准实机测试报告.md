# 固定初始航向基准实机测试报告

- 日期：2026-11-11（Asia/Shanghai）
- 项目：`CourceCar`，VEX V5，PROS Kernel 4.2.2。
- 测试模式：`VehicleConfig::enableHeadingReferenceTest=true`；只采集 IMU，不运行遥控、居中或点动。
- 操作分工：用户操作实车、启动采集；助手读取 CSV 并分析。
- 阶段结论：**结束本轮测试。固定基准保持、相对角响应和约 20 秒静态稳定性已获得实机证据。**
- 限定：不是完整 IMU 标定、绝对角度精度验收，也不是航向闭环电机测试；未覆盖项仍保留待验证。

## 1. 功能与预期

关联 IMU-004 / IMU-011。`imu::StartupHeading` 保存独立于底盘临时目标的初始航向 ψ₀。
程序初始化至少 5 秒、IMU 有效、零偏已测且满足旋转静止窗口后才锁存。
旋转静止判断不能排除纯平移，采样时仍需用户保持整车静止。

- 锁存后，手动转动车身不应改变 ψ₀ 或锁存时刻。
- 相对角 `wrap(工程航向 − ψ₀)` 应随车身转动变化。
- 按物理方向标记复位后，相对角应接近零；人工对齐误差与传感器误差不可混为一谈。
- 静止期间不应出现明显持续漂移。
- 程序重启重新建立零点；比赛禁用与普通停车应保留零点，但该生命周期边界需单独验证。

## 3. 最终静态记录的统计

来源：`heading_static_only.csv`；程序计时 373.537～393.437 秒，200 帧，100ms 间隔。
命令设置采集 20 秒，首末帧跨度为 19.9 秒是离散采样的正常表现。

| 指标 | 结果 |
| --- | --- |
| 初始基准 | 786 mrad，约 45.03°，全程不变 |
| 锁存时刻 | 5.517 秒，全程不变 |
| 相对角首值/末值 | 均为约 91.272° |
| 相对角最小/最大 | 91.215° / 91.272° |
| 相对角峰峰值 | 1 mrad，约 0.0573° |
| 相对角标准差 | 约 0.0080° |
| 工程航向原始遥测 | 2379 mrad，全程相同 |
| 角速度遥测 | 全程 0 mrad/s |
| 数据有效性 | 全程有效，无时间戳间隔异常 |

结论：在本次约 20 秒和整数遥测分辨率下，未观察到明显持续漂移。
相对角的 1 mrad 波动处于遥测量化尺度；不能据此宣称零噪声、长期零漂移或绝对精度达到该数值。
相对角约 91° 是当前车身摆放方向，不是应强制归零的误差。

## 4. 验证状态与边界

| 项目 | 状态 | 依据/限制 |
| --- | --- | --- |
| 固定初始基准不随手动旋转改变 | 已验证 | 五份记录中的 initial/lock 各自保持不变 |
| 相对角响应手动旋转 | 已验证 | 第二份记录接近 90°，其余记录也能反映转动 |
| 人工复位接近零 | 已观察 | 第二份约 +1.26°；未用精密角度基准，不能当绝对角度精度标定 |
| 约 20 秒静态稳定性 | 已验证 | 最终补录相对角波动约一个遥测单位 |
| 满足初始化门控才锁存 | 部分验证 | 记录的锁存时刻均晚于 5s，首次采集时已锁存；缺少锁存前完整轨迹 |
| 比赛禁用/使能保留基准 | 实机待验证 | 未提供该操作的记录；仅软件逻辑和主机测试证据 |
| 校准后、锁存前转动会延后锁存 | 实机待验证 | 主机单测覆盖；本轮缺少明确现场阶段标记 |
| 重启后重新初始化 | 部分验证 | 不同运行出现新的计时/锁存值；未完整记录重新校准的全过程 |
| 电机航向保持、定位、居中、转角防碰 | 不在本轮范围 | 本轮电机不执行运动控制 |

未记录电池电压、环境温度、精密转角基准及传感器温度；不将本轮结果外推到长期运行或不同环境。
